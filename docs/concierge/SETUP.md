# تشغيل مساعدة المدير الصوتية — JorMall

هذه إضافة برمجية إلى مشروع Phase 5 المرفق، وليست صورة أو صفحة عرض منفصلة. ملفات الواجهة الفعلية وواجهات API وحفظ المسودة والترحيل موجودة داخل المشروع. **لم تُختبر الاتصالات المدفوعة أو قاعدة PostgreSQL الفعلية في بيئة التحرير؛ اقرأ نتائج الفحص أدناه قبل النشر.**

## 1. ما سيظهر للمدير

بعد تسجيل الدخول وتغيير كلمة المرور الأولية عند اللزوم، تظهر للمدير المخوّل دائرة زرقاء/بيضاء متحركة في المنتصف. خلفية النظام محجوبة، ولا توجد نافذة محادثة جانبية. تظهر خانة الاسم وحدها؛ بعد قبول الاسم تختفي وتظهر مقدمة قصيرة وخيارا الإعداد اليدوي أو الصوتي. هناك بديل نصي عند تعذر الصوت. النص العربي للمساعدة باللهجة الأردنية وبصيغة أنثى، مع واجهة إنجليزية أيضًا.

الاختيار الصوتي يوضح ضرورة مكان هادئ وتخصيص نحو ربع ساعة، ثم موافقة على معالجة البيانات لدى المزودين. المحادثة تجمع الفروع ومواعيد العمل والخدمات والغرف والموظفين في **مسودة**. عند ذكر PDF/ملف تظهر خانة الرفع فقط عند الحاجة. لا يظهر تأكيد القراءة قبل عودة معالجة الملف. تبقى الدائرة موجودة أثناء الانتظار.

زر «المراجعة والحفظ» يعرض الحقول القابلة للتعديل، والنواقص، وصلاحيات حسابات الموظفين. كلمات المرور الأولية تُدخل في المراجعة فقط، ولا تُرسل إلى النموذج. الحفظ يحتاج تأكيدًا صريحًا ويستخدم جداول البرنامج الحقيقية ومعاملة واحدة. إغلاق المساعدة أو اختيار اليدوي يعيد المدير للبرنامج. يمكن فتحها لاحقًا من زر المساعدة؛ الجلسة المكتملة أو اليدوية لا تعاود الظهور تلقائيًا عند كل دخول.

## 2. الإعدادات المطلوبة

احتفظ بإعدادات السيرفر الحالية `DATABASE_URL` و`SESSION_SECRET`. أضف القيم التالية إلى **Replit Secrets أو متغيرات بيئة السيرفر**:

```dotenv
CONCIERGE_ENABLED=true
OPENAI_API_KEY=ضع_مفتاح_OpenAI_هنا
CONCIERGE_LLM_MODEL=gpt-4.1
CONCIERGE_REALTIME_MODEL=gpt-realtime-2.1
CONCIERGE_REALTIME_VOICE=marin
```

يستخدم التطبيق OpenAI Realtime عبر WebRTC للمحادثة الصوتية المباشرة، وصوت `marin` افتراضيًا. يوجّه النموذج للكلام بعامية أردنية طبيعية، لكن اللكنة ليست مضمونة حرفيًا. الصوت الثابت قبل بدء المحادثة يستخدم OpenAI TTS.

القيم النموذجية أعلاه توضيحية وليست مفاتيح. يوجد قالب فارغ `.env.concierge.example`. لا يحمّل المشروع ملف `.env` تلقائيًا؛ استخدم Secrets أو صدّر المتغيرات قبل تشغيل السيرفر. لا تضع المفاتيح في `VITE_*` أو الواجهة أو Git. لا تغيّر مفاتيح الجلسات/قاعدة البيانات القائمة لمجرد تفعيل هذه الميزة.

`CONCIERGE_ENABLED=false` يعطّل المساعدة الجديدة. غياب مفتاح OpenAI لا يختلق اتصالًا: يبقى الإدخال اليدوي متاحًا، ويظهر نقص التهيئة. النص والصوت يحتاجان مفتاح OpenAI بصلاحية Realtime وResponses وTTS ورصيد مناسب. إعدادات المساعد القديم `AI_ASSISTANT_*` مستقلة ولم تتغير. يتطلب اختيار نموذج نصي بديل أن يدعم Responses وStructured Outputs وPDF عند استخدام ملفات PDF.

## 3. تشغيل المشروع وترحيل قاعدة البيانات

استخدم بيئة المشروع Node 24/Replit وpnpm 10، مع ملف القفل الحالي؛ لم تُضف أي مكتبات تطبيق جديدة. من مجلد المشروع:

```bash
pnpm install --frozen-lockfile
node scripts/concierge-preflight.mjs
```

الفحص الأخير يعرض **وجود** الإعدادات فقط ولا يطبع قيمها؛ نجاحه ليس اختبار اتصال.

أضيف ترحيل **`0004_manager_voice_concierge.sql`** لإنشاء جدول `manager_onboarding`. لا يعيد كتابة الجداول التشغيلية. جميع الترحيلات الخمسة المرفقة مكتوبة يدويًا، ولم تُنفذ هنا. توليد snapshots ومطابقة المخطط والتحقق من مسارات الترقية ما زال مطلوبًا.

**اختر المسار بحسب تاريخ قاعدة البيانات، بعد نسخة احتياطية وعلى نسخة تجريبية أولًا:**

| الحالة | الخطوة الصحيحة |
|---|---|
| قاعدة تجريبية فارغة | `pnpm --filter @workspace/db run migrate` لتطبيق 0000–0004، ثم التحقق من الجداول والقيود. |
| قاعدة Phase 5 عليها نفس سجل الترحيلات 0000–0003 بالضبط | راجع السجل والمخطط أولًا؛ أمر `migrate` يفترض أن يطبق 0004 فقط. اختبر نسخة من القاعدة قبل الإنتاج. |
| قاعدة أُنشئت/عُدلت سابقًا بـ `push` | لا تعِد تشغيل ترحيلات البداية. يجب مطابقة المخطط وسجل الترحيلات واعتماد مسار ترقية مناسب؛ راجع `lib/db/migrations/README.md`. |
| قاعدة تطوير قابلة للتخلص منها تستخدم push عمدًا | `pnpm --filter @workspace/db run push`؛ هذا wrapper يركّب أيضًا حمايات المواعيد والمخزون. |

لا تستخدم `push-force` أو تحذف سجلات الترحيل لتجاوز تعارض. مساعد snapshots صار يشمل مخطط الإضافة؛ إذا وجد سلسلة جزئية يتوقف بدل خلط المعرفات. لا تمسح snapshots مطبقة لاستكمال السلسلة؛ يلزم توفيقها بواسطة المطور.

شغّل الـAPI والواجهة كعمليتين منفصلتين:

```bash
PORT=5000 pnpm --filter @workspace/api-server run dev
PORT=19880 BASE_PATH=/ pnpm --filter @workspace/jormall run dev
```

الوصول للواجهة يكون عبر عنوان تشغيلها أو رابط Replit. حافظ على بروكسي `/api` الموجود وسياق تسجيل الدخول نفسه. **الميكروفون يحتاج HTTPS أو localhost**؛ عنوان HTTP عادي على الشبكة ليس بديلًا صالحًا. قد يمنع المتصفح تشغيل التحية تلقائيًا؛ يظهر زر تفعيل الصوت عند الحاجة. لا نحاول تجاوز إذن الميكروفون أو سياسة التشغيل التلقائي.

## 4. المحادثة والملفات والصلاحيات

الصوت الآن محادثة مباشرة عبر WebRTC مع OpenAI Realtime، مع كشف نهاية الكلام والمقاطعة. إغلاق المساعدة أو الصفحة يوقف الميكروفون والاتصال؛ التحويل للنص أو الرفع يوقف الاستماع مؤقتًا. مفتاح OpenAI يبقى على الخادم ولا يُرسل إلى المتصفح.

الرفع المدعوم الآن: **PDF، TXT، CSV، JSON فقط**؛ حتى 8 MB، والملفات النصية UTF-8 حتى 60,000 محرف. لا توجد ادعاءات بدعم DOCX/XLSX/صور منفصلة. PDF يُرسل كملف فعلي إلى نموذج يدعم PDF، وليس مجرد اسم ملف. جودة استخراج الجداول/المسح تعتمد على الملف والمزود؛ فشل القراءة يظهر صراحة ولا يحفظ بيانات تشغيلية. ملف خبيث أو تعليمات داخل الملف لا يمنح صلاحيات أدوات/SQL. راجع الاستخراج حتى عند ظهور «تمت القراءة».

المساعدة الجديدة مقيدة بالمدير مع `settings.manage` وبصلاحية إدارة المورد عند حفظه. تستطيع إنشاء فروع وخدمات وغرف وموظفين، وتعديل بيانات فرع قائم بعد فحص تغيره. لا تعدّل تلقائيًا حسابات موظفين قائمة ولا تحذف سجلات. يمكن ربط الموظف بخدمات وفرع وساعات عمل وفترات استراحة، مع صلاحيات يراجعها المدير ولا تتجاوز ما يملك. يلزم إكمال البريد وكلمة المرور وغيرها من البيانات الناقصة لإنشاء حساب؛ لا تختلقها المساعدة.

السياق يقرأ موارد الإعداد المسموحة من قاعدة المؤسسة نفسها (حتى 200 سجل لكل نوع)، وأعدادًا تشغيلية مسموحة وروابط صفحات محددة. ليس وصولًا مفتوحًا لكل قاعدة البيانات. عند تغير صلاحيات المدير تتوقف قراءة المسودة السابقة حتى إعادة بدء جلسة وفق الصلاحيات الجديدة. المساعد القديم «مساعدة الموظفين» ما زال متاحًا لأدوات المواعيد الآمنة. **لا حجز/إلغاء آلي للمواعيد، ولا خصم مخزون أو إرسال رسائل بواسطة المساعدة الجديدة**؛ هذه العمليات تبقى في شاشاتها القائمة وتأكيداتها.

## 5. البيانات والحدود

المسودة، الملخصات، وآخر 24 رسالة تحفظ في PostgreSQL ضمن المؤسسة والمدير. لا تُخزن ملفات الصوت أو بايتات الملفات أو مفاتيح المزود أو كلمات المرور الأولية في جدول المساعدة. يحذف الحفظ النهائي محتوى المحادثة والمسودة وملخصات الملفات من هذا الجدول، مع الاحتفاظ بنتيجة الحفظ. إعادة تهيئة جلسة `/start` قديمة أكثر من 30 يومًا تصفّر محتواها؛ **هذا ليس حذفًا دوريًا مضمونًا بعد 30 يومًا** ولا يشمل نسخ قواعد البيانات الاحتياطية. لا يوجد daemon تنظيف مضاف.

الحدود اليومية لكل مدير بتوقيت UTC: 80 طلب محادثة، 10 ملفات، 24,000 محرف TTS، و4 اتصالات صوتية مدة كل منها القصوى 15 دقيقة. الحد الأقصى للمسودة 50 سجلًا ولمخرجات الجولة 20 سجلًا. هذه حواجز استخدام، **وليست سقف فاتورة بالدينار/الدولار**. قد يُستهلك الطلب المحجوز حتى لو فشل أو انقطع. إعادة نفس الجولة المكتملة أو تأكيد الحفظ بنفس رقم المراجعة لا تنشئ سجلات جديدة.

قد تُحتسب كلفة جلسة OpenAI Realtime أثناء بقائها متصلة؛ أغلقها عند التوقف الطويل. الصوت والنص والمستندات المرسلة تذهب إلى OpenAI. `store:false` لطلبات النص ليس ضمانًا لعدم احتفاظ المزود بالبيانات. لا ترفع تاريخ مرضى أو ملاحظات حساسة أو أسرارًا أو كلمات مرور ضمن إعداد المؤسسة. راجع سياسات الاحتفاظ والعقود الفعلية قبل استعمال بيانات حقيقية.

## 6. ما تم اختباره وما لم يتم

نتائج التنفيذ في `verification/concierge/summary.json` وملفات السجلات:

- 331 فحصًا سابقًا بقيت ناجحة، و78 فحصًا جديدًا: 59 للمنطق الخالص، 13 لعقود HTTP بمحاكاة المزود، و6 لتوكيدات المصدر.
- فحص TypeScript صارم لوحدات واجهة المساعدة الثماني الخالية من تبعيات React، وللمنطق الخالص وموصلات المزود. هذا ليس typecheck لكامل الـworkspace.
- 33 فحصًا في Chromium على **واجهة المساعدة الإنتاجية نفسها**: الحركة الحقيقية، إخفاء الاسم، التركيز، العربية/الإنجليزية، شاشة 390px، الملف قيد القراءة، المراجعة وكلمات المرور والتأكيد. النقل إلى API كان ببيانات اختبار صناعية، وليس Express/PostgreSQL الحقيقيين، والغلاف React الكامل لم يُشغّل. ملفات صور التحقق دليل من المتصفح وليست جزءًا من تصميم التطبيق أو خلفية البرنامج الفعلية.
- مسار الرسم Canvas2D المتحرك اجتاز الفحص؛ WebGL لم يتوفر في متصفح الحاوية ولذلك shader غير متحقق وقت التشغيل هنا.
- أضيفت 24 حالة PostgreSQL/Express في `src/test/concierge.test.ts`، **مكتوبة ولم تُنفذ**. لم تتوفر pnpm أو تبعيات التطبيق أو PostgreSQL. لم تُنفذ الترحيلات أو البناء الكامل أو الاختبارات الحقيقية للميكروفون/المزودين. وجود موصل برمجي أو اختبار HTTP بمحاكاة لا يعني نجاح اتصال مدفوع.

للفحص دون طلبات مدفوعة بعد تثبيت TypeScript:

```bash
node scripts/checks/concierge-offline.mjs
# عند استخدام تثبيت TypeScript عام فقط:
TYPESCRIPT_PATH="$(npm root -g)/typescript" node scripts/checks/concierge-offline.mjs
```

لإعادة فحوص المكون في بيئة لديها Python Playwright وChromium في `/usr/bin/chromium`:

```bash
node scripts/checks/build-concierge-ui-test.mjs
# بنفذة طرفية أولى — fixture محلي صناعي، وليس تطبيق الإنتاج:
python scripts/checks/concierge-ui-harness.py
# بنفذة ثانية:
python scripts/checks/concierge-component-browser.py
```

يمكن تعيين `TYPESCRIPT_PATH` لسكريبت البناء أيضًا. الخادم الصناعي محصور في localhost:18763. ملف `test-tone.mp3` إن استُخدم في هذه الفحوص مجرد نغمة اختبار، وليس صوت Soniox. هذه الأدوات تحت `scripts/checks` لا تدخل بناء Vite الإنتاجي.

قبل النشر، بعد تثبيت التبعيات وترحيل قاعدة **تجريبية قابلة للتخلص منها**:

```bash
export TEST_DATABASE_DISPOSABLE=1
bash scripts/checks/verify-concierge.sh
```

هذا يشمل typecheck الكامل، الفحوص السابقة والجديدة، جميع اختبارات الـAPI، وبناء الواجهة والـAPI. لا يشغّل ترحيلًا تلقائيًا أو طلب مزود مدفوعًا. توقف وأصلح أي فشل؛ لا تعتبر الفحوص الجزئية بديلًا عنه.

## 7. القبول الحقيقي المتبقي

اختبر مديرًا تجريبيًا بعد تغيير كلمة المرور، على شاشة مكتبية و390px بالعربي والإنجليزي. أدخل الاسم وتأكد من اختفائه، جرّب اليدوي ثم أعد فتح المساعدة. أضف مفتاح اختبار OpenAI، ووافق على معالجة بيانات صناعية فقط، ثم جرّب التحية الفعلية وجودة اللهجة وفهم OpenAI للأسماء والأرقام. قد تحتسب هذه الخطوة تكلفة لدى المزود.

اطلب إضافة فرع وخدمة وغرفة وموظف، وارفع PDF صناعيًا صغيرًا، وتحقق من الحقول المفقودة والقراءة الفعلية. عدّل المسودة، راجع الصلاحيات وأدخل كلمة مرور أولية ثم احفظ. افتح الصفحات التشغيلية نفسها للتأكد من السجلات والربط، وجرّب تسجيل دخول الموظف وتغيير كلمته. أعد إرسال تأكيد الحفظ للتأكد من عدم التكرار. اختبر مدير مؤسسة أخرى وحساب سكرتير وسحب صلاحية مدير أثناء طلب جارٍ. اختبر قطع الشبكة ومفتاحًا خاطئًا وإغلاق الميكروفون وانتهاء 15 دقيقة وغياب WebGL.

شغّل أيضًا قبول المواعيد/قائمة الانتظار/المخزون القديم؛ الربط الجديد ليس إثباتًا لسلامة كل الإصدار. بعد نجاح هذه الخطوات على النسخة التجريبية، خطط للنشر مع نسخة احتياطية ومراقبة الفاتورة وسجلات الأخطاء المنقحة.
